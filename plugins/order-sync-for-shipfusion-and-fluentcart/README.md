# Order Sync for ShipFusion and FluentCart

Send paid FluentCart orders to your ShipFusion warehouse and get tracking and stock back automatically.

Part of the UpFluent add-ons for the Fluent suite: https://upfluent.io/order-sync-for-shipfusion-and-fluentcart/

- Requires WordPress 6.7+, PHP 7.4+, FluentCart 2.3+ and a ShipFusion account.
- Install: Plugins → Add New → Upload, then FluentCart → More → ShipFusion.
- Support: https://upfluent.io/support/
